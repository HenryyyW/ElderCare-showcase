# Feature Overview

## Home Safety Monitoring

The monitoring experience surfaces camera state, connection health, routine activity, and events requiring attention.

## Privacy Overlay

Pose visualization supports a privacy-aware preview by replacing the visible person with an abstract representation while retaining useful movement information.

## Events

Routine activities such as sitting, walking, or eating are presented as events. Urgent and warning levels are reserved for situations that require caregiver attention.

## Daily Reports

Reports summarize the latest completed day and include:

- Total recorded activity
- Category proportions
- Most common activities
- Urgent and warning counts
- Activity time range
- A plain-language summary

## Care Agent

The Agent can summarize daily activity, answer practical care questions, and use citations when information comes from local care knowledge or official ERC pages.

## Shared Care Group

The shared-care model lets an older adult, family members, and caregivers view the same care context and coordinate follow-up actions.
