# Screenshots

Place sanitized product screenshots in this directory.

Recommended files:

- `overview.png` - home safety overview and camera status
- `events.png` - routine events and attention levels
- `reports.png` - completed daily report and donut chart
- `agent.png` - Care Agent conversation
- `settings-care-group.png` - shared family care-group settings

Before adding screenshots, remove faces, names, addresses, camera URLs, API endpoints, tokens, and personal activity records.
